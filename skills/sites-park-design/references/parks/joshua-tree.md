# Joshua Tree

**Thesis:** deliberate elements in an open field; angular interruptions create focus.

## Palette seeds

| Ingredient | Hex | Possible role |
| --- | --- | --- |
| Chalk | `#F2EDE1` | Main surface |
| Night | `#202724` | Text or inverse surface |
| Ochre | `#B88232` | Small emphasis |
| Stone | `#ADA28D` | Dividers or secondary surface |
| Sky | `#316C88` | Action candidate |

## Translation

- Compose a few unequal zones around a strong anchor. In a tool, isolate the main input and align supporting results along a clear axis; avoid a decorative opening hero.
- Use compact, firm headings and an open, readable body face. Make the type hierarchy decisive without making the title enormous.
- Alternate generous space between groups with tightly related controls. Maintain practical density inside working areas.
- Favor clipped corners, straight divisions, and occasional offset alignment.
- Signature detail: a short angular rule at major section boundaries, repeated consistently and sparingly.

**Avoid:** cactus icons, faux distressed desert posters, beige-on-beige text, or empty space that pushes the task below the fold.

**Mobile:** collapse to one anchor and a sequential supporting flow; reduce outer gaps before reducing type size.
