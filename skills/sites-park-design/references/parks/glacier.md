# Glacier

**Thesis:** strong axes and deep divisions; large-scale orientation makes smaller details navigable.

## Palette seeds

| Ingredient | Hex | Possible role |
| --- | --- | --- |
| Slate | `#253A4A` | Text or navigation |
| Ice | `#EBF4F7` | Main surface |
| Lake | `#166B78` | Action candidate |
| Ridge | `#8D9DA9` | Dividers or muted surfaces |
| Berry | `#A13F54` | Sparse accent |

## Translation

- Use a strong index/detail split, clear column axes, or an overview that leads directly into fine detail. Scale contrast should express information hierarchy.
- Pair firm geometric headings with a highly legible body face; use distinct label and value hierarchy in dense material.
- Group related detail tightly while maintaining deep, consistent gutters between major regions.
- Favor sharp seams, aligned edges, and an occasional diagonal separator outside reading and control areas.
- Signature detail: a persistent vertical orientation rule connecting overview labels to the current detail region.

**Avoid:** mountain silhouettes, decorative topographic maps, diagonal text, or a generic blue SaaS dashboard with no structural interpretation.

**Mobile:** convert the split into overview then detail with clear back/context controls when needed; preserve the current selection.
