# Bryce Canyon

**Thesis:** repeated vertical beats with varied height; repetition enables comparison while edges create hierarchy.

## Palette seeds

| Ingredient | Hex | Possible role |
| --- | --- | --- |
| Rust | `#A3472B` | Action candidate or strong accent |
| Peach | `#F1C4A4` | Supporting surface |
| Midnight | `#202B43` | Text or inverse band |
| Limestone | `#FAF3E8` | Main surface |
| Gold | `#CC963E` | Limited highlight |

## Translation

- Build comparison rails, aligned columns, or repeated row groups with a strong vertical reading rhythm. Actual content determines height; do not distort data to resemble a landscape.
- Use a narrow display face for short headings and tabular numerals for comparison; keep body copy comfortably proportioned.
- Repeat a tight spacing unit within groups, then introduce a larger step at meaningful boundaries.
- Prefer stepped section edges, strong vertical rules, and firm rectangular controls.
- Signature detail: a stepped rule marking a change of group or priority, never a fabricated chart.

**Avoid:** identical three-card feature grids, arbitrary masonry ordering, decorative bar charts, or orange used for every semantic state.

**Mobile:** convert comparisons to aligned rows with persistent labels; keep meaningful order and comparable values together.
