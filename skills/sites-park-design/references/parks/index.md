# Park index

Read this index to shortlist; then read only the selected profile. These are creative interpretations of landscape qualities, not official identities or factual visitor guides. Palettes are seeds, not accessible themes. Test actual text pairs after assigning roles.

| Park | Spatial character | Useful when the brief calls for | Profile |

No park owns a product category. The same tracker could use Acadia's compact clusters or Bryce's vertical comparison rhythm. Choose through the task, not a lookup table that gives every dashboard the same park. A requested park outside this starter set is welcome: research it with authoritative park sources and create an original interpretation before use.
